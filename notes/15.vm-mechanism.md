# Hardware-based address translation

- The hardware changes the **virtual address** provided by the instruction to a **physical address**.
- The OS sets up hardware and manages memory _(keeps track of free/used locations, intervene to maintain control)_.
- **Illusion**: Each program has its own private memory.

# 1st attempt - Assumptions

- User's address space is placed contiguously in memory.
- Size of address space is less than the size physical memory.
- Each address space is exactly the same size.

# Dynamic relocation (based-and-bounds)

- Use 2 hardware registers within the CPU:
  - **base**
  - **bounds** (or **limit**)
- Memory reference generated by the process is a **virtual address**.
- Address translation:
  - `physical_addr = virtual_addr + base`
- The **bounds** (or **limit**) register helps with **protection** _(ensures memory references are within bounds)_.
- The part of the processor that helps with address translation is called the **memory management unit (MMU)**.

# Hardware support needed

- CPU must have the pair of **base** and **bounds** registers, part of the MMU.
- Hardware must provide **privileged** instructions to modify these registers.
- CPU must generate **exceptions** when user program tries to access memory illegally.

# OS issues

- When a process is created, the OS must find space for its address space in (physical) memory _(allocate from **free list**)_.
- When a process is terminated, the OS must reclaim all of its memory _(put back on **free list**, clean up associated data structures)_.
- When a context switch occur, the OS must save/restore values of the base and bounds registers to/from memory _(since there's only 1 base-and-bounds register pair on each CPU)_.
  - When a process is stopped, the OS can move its address space by copying the address space and updates the saved **base** register.
- The OS must provide **exception handlers** _(installed at boot time)_.

# Inefficiencies

- **Internal fragmentation**: Each address space takes a fixed contiguous block of physical memory but only use a small fraction of it.

```
| Code  |
| Heap  |
| ...   |   <- wasted
| Stack |
```
